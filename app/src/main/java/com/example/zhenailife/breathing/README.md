# 呼吸引導滑雪動畫功能

本功能實現了一個沉浸式的呼吸引導體驗，通過滑雪動畫視覺化呼吸過程，幫助用戶進行冥想呼吸練習。

## 架構設計

呼吸引導功能採用模塊化設計，主要包含以下組件：

1. **BreathingController**：呼吸控制器
   - 管理呼吸階段（吸氣、閉氣、吐氣、放鬆）
   - 控制呼吸週期的時間和進度
   - 提供呼吸狀態的實時監控

2. **ParallaxSkiingCanvas**：視差滾動畫布
   - 實現背景、地面和角色的視差效果
   - 根據呼吸階段調整動畫效果
   - 處理圖像繪製和特效實現

3. **BreathingAnimationScreen**：呼吸動畫畫面
   - 整合呼吸控制器和視差畫布
   - 提供完整的用戶體驗

4. **BreathingNavigationScreen**：導航入口
   - 介紹呼吸引導功能
   - 作為主畫面到呼吸動畫的橋樑

## 呼吸引導流程

呼吸引導遵循以下流程：

1. **吸氣階段（上坡）**
   - 時長：4秒
   - 視覺效果：背景亮度提高，角色上升

2. **閉氣階段（跳躍）**
   - 時長：2秒
   - 視覺效果：背景最亮，角色懸浮

3. **吐氣階段（下坡）**
   - 時長：4秒
   - 視覺效果：背景變暗，出現霧氣，角色下降

4. **放鬆階段（平地）**
   - 時長：2秒
   - 視覺效果：正常亮度，角色平穩滑行

## 如何使用

在主畫面點擊「呼吸引導練習」按鈕，進入呼吸引導導航畫面，然後點擊「開始呼吸練習」進入呼吸動畫畫面。

## 自定義和擴展

1. **修改呼吸週期時間**：
   在 `BreathingController.kt` 文件中，可以調整各階段的持續時間：
   ```kotlin
   val inhaleDuration = 4000L  // 吸氣時間（毫秒）
   val holdDuration = 2000L    // 閉氣時間（毫秒）
   val exhaleDuration = 4000L  // 吐氣時間（毫秒）
   val relaxDuration = 2000L   // 放鬆時間（毫秒）
   ```

2. **替換圖像資源**：
   - 替換 `res/drawable/ski_background.xml`
   - 替換 `res/drawable/ski_ground.xml`
   - 替換 `res/drawable/ski_character.xml`

   或直接添加PNG圖片資源。

3. **調整視差效果**：
   在 `ParallaxSkiingCanvas.kt` 文件中，可以調整滾動速度和視覺效果參數。
